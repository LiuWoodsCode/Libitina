# Project Libitina
Project Libitina is a project to create a shell for Linux on mobile phones that can appeal to regular users while also being performant on low power devices / devices without graphics acceleration.

> [!WARNING]
> You really ahouldn't be using this on your main device right now, as it is very early in development.

# Tested devices
Currently, this project has only been tested on the LG Google Nexus 5 (hammerhead) running postmarketOS edge.
